Fullstack Developer

Deskripsi

Kami sedang mencari seorang Full-Stack Developer yang handal untuk bergabung dengan tim teknologi kami. Anda akan bertanggung jawab merancang, mengembangkan, dan memelihara aplikasi web dari awal hingga tahap perilisan. Peran ini menuntut kemampuan untuk mengelola antarmuka pengguna (front-end) sekaligus infrastruktur dasar dan basis data (back-end).

Requirements

  1. Menguasai teknologi dasar web seperti HTML5, CSS3, dan JavaScript (ES6+)/TypeScript.
  2. Kemampuan merancang, mengoptimalkan, dan mengelola database Relasional (PostgreSQL, MySQL) maupun Non-Relasional (MongoDB, Redis).
  3. Pengalaman menggunakan Git untuk version control dan kolaborasi tim (GitHub/GitLab).

DevOps Engineer

Deskripsi

Kami sedang mencari seorang DevOps Engineer yang berpengalaman untuk menjembatani celah antara tim pengembangan perangkat lunak (Development) dan tim operasional (Operations). Anda akan bertanggung jawab untuk membangun, mengotomatisasi, dan memelihara infrastruktur cloud, pipeline CI/CD, serta memastikan sistem aplikasi kami berjalan dengan performa tinggi, aman, dan memiliki tingkat ketersediaan yang tinggi (highly available).
